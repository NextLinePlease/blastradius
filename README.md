# BlastRadius

A safety check for software deployments that predicts failure probability, estimates downstream blast radius, and recommends a rollout plan for a simulated microservice fleet.

## Scope

All data is simulated. Services, traffic, and faults are generated by this project's own load generator and chaos injector.

Labels must be derived from injected faults and measured downstream impact, not randomly assigned.

## Problem Statement

In a microservice architecture, a failure in one service can propagate to its dependent services.

A deployment that appears safe in isolation can introduce failures across multiple services.

BlastRadius aims to analyze these dependencies, estimate deployment risk, identify potentially affected services, and recommend safer rollout strategies.

## Technology Stack

- **C++:** Rate-limiting implementation.
- **Python:** Backend services and ML pipeline.
- **FastAPI:** Microservice and API development.
- **Redis:** Rate limiting and telemetry storage.
- **PostgreSQL:** Service registry and dependency information.
- **Docker Compose:** Simulated multi-service environment.
- **Git and GitHub:** Version control and project tracking.
